## 🔍 Hackathon #1: Digital Forensics & Log Analysis

**โจทย์:** ค้นหาและวิเคราะห์ข้อมูล/ร่องรอยที่แฮกเกอร์หลงเหลือไว้ในระบบ
**สิ่งที่โจทย์กำหนดให้สืบค้น:**
- 👤 **Who are they?** (ใครคือผู้อยู่เบื้องหลังการโจมตี?)
- 📅 **When & HOW?** (เหตุการณ์เกิดขึ้นเมื่อใด และใช้วิธีการใด?)
- 📢 **Tell people** (สรุปข้อมูลและแจ้งผู้เกี่ยวข้อง)
- 🎁 **Hidden Bonus** (ข้อมูลโบนัสที่ซ่อนอยู่)

---

### 🛠️ วิธีการและชุดคำสั่งในการแกะรอย (Log Analysis Steps)

#### 1. ค้นหาคำสั่งหรือไฟล์ที่มีความเกี่ยวข้องกับแฮกเกอร์
เริ่มต้นค้นหาคีย์เวิร์ด `hackathon#1` ทั่วทั้งระบบเพื่อหาไฟล์ Log ที่เกี่ยวข้อง:
```bash
grep -r "hackathon#1" / 2>/dev/null
```
> [!NOTE]
> ผลลัพธ์จากการรันคำสั่งดังกล่าวจะพบไฟล์ log ที่ชื่อว่า `cart_web.log` ซึ่งเป็นไฟล์ที่มีคำว่า `hackathon#1` ซ่อนอยู่ภายใน

#### 2. ค้นหารายการ IP Address ของแฮกเกอร์
ใช้คำสั่งคัดกรองเฉพาะบรรทัดที่เกิด HTTP Status Error `500` หรือ `504` เพื่อระบุ IP Address ของแฮกเกอร์:
```bash
grep -E '\| 500 \|\|\| 504 \|' cart_web.log | cut -d '|' -f 2 | tr -d ' ' | sort | uniq
```
* **คำอธิบายคำสั่ง:**
  - `grep -E`: ค้นหาบรรทัดที่มี Error `500` หรือ `504`
  - `cut -d '|' -f 2`: ตัดเอาเฉพาะคอลัมน์ที่ 2 (IP Address)
  - `tr -d ' '`: ลบช่องว่างส่วนเกิน
  - `sort | uniq`: จัดเรียงและตัด IP Address ที่ซ้ำออก เพื่อให้ได้เฉพาะ Unique IPs

#### 3. ตรวจสอบจำนวนครั้งในการเข้าถึง (Access Count) ของแฮกเกอร์
นับจำนวนครั้งที่แต่ละ IP Address ที่ผิดปกติ พยายามร้องขอ (Request) เข้ามายัง Server เพื่อตรวจหาพฤติกรรมผิดปกติ:
```bash
grep -E '\| 500 \|\|\| 504 \|' cart_web.log | cut -d '|' -f 2 | tr -d ' ' | sort | uniq -c
```
> [!TIP]
> คำสั่ง `uniq -c` เป็นคำสั่งมาตรฐานของ Linux ในการนับจำนวนบรรทัดที่ซ้ำกัน ซึ่งช่วยระบุปริมาณความพยายามในการเข้าถึงได้อย่างชัดเจน

#### 4. วิเคราะห์ความหน่วงของระบบ (Response Time Latency)
ค้นหาชั่วโมงที่มี Response Time สูงเกินปกติ (> 5000 ms) เพื่อระบุช่วงเวลาที่ Server โดนรบกวน:
```bash
awk -F ' \\| ' '$6 > 5000 {print substr($1, 1, 13)}' cart_web.log | sort | uniq -c
```
* **คำอธิบายคำสั่ง:**
  - `awk -F ' \\| '`: แบ่งคอลัมน์ด้วยตัวแบ่ง `|`
  - `$6 > 5000`: ตรวจสอบคอลัมน์ที่ 6 (Response Time) ว่าเกิน 5000 ms หรือไม่
  - `{print substr($1, 1, 13)}`: ดึงเฉพาะข้อมูล วันที่และชั่วโมง (เช่น `YYYY-MM-DD HH`) จากคอลัมน์แรก
  - `sort | uniq -c`: เรียงลำดับและนับจำนวนครั้งในแต่ละชั่วโมง

#### 5. แกะรอยชื่อลับของแฮกเกอร์ (Deciphering Hacker's Name)
แฮกเกอร์คนนี้มีพฤติกรรมเข้าถึงไฟล์แปลกๆ โดยการฝังตัวอักษรพิมพ์ใหญ่ไว้ท้ายชื่อไฟล์/พาธที่เขาเข้าถึงแบบเรียงลำดับเวลา (Timestamp) เราสามารถสกัดตัวอักษรเหล่านี้ออกมาได้ด้วยชุดคำสั่ง:
```bash
grep -E '/[a-zA-Z0-9_]+[A-Z_]$|/index[A-Z_]\.html' cart_web.log | awk -F ' \\| ' '{
    timestamp = $1
    path = $4
    
    if (path ~ /\/index[A-Z_]\.html/) {
        letter = substr(path, 7, 1)
    } else {
        letter = substr(path, length(path), 1)
    }
    
    if (letter != last_letter) {
        if (last_letter != "") {
            print "----------------------------------------"
        }
        print "ตัวอักษร: " letter
        print "  เวลาที่ตรวจพบ: " timestamp
        last_letter = letter
        count = 1
    } else if (count < 2) {
        print "  เวลาที่ตรวจพบ: " timestamp
        count++
    }
}'
```
* **คำอธิบายคำสั่ง:**
  - `grep -E ...`: คัดกรองเฉพาะบรรทัดที่แฮกเกอร์ฝังตัวอักษรไว้
  - `awk -F ' \| ' ...`: แบ่งข้อมูลออกเป็นคอลัมน์ โดยคอลัมน์ $1 คือเวลา และ $4 คือ Path URL
  - การทำงานภายใน `awk`: ใช้ตัวแปร `last_letter` เพื่อจำว่าตัวอักษรก่อนหน้าคืออะไร และใช้ตัวแปร `count` เพื่อนับจำนวนครั้งที่แสดงผลเวลาไปกี่ครั้ง (แสดงสูงสุด 2 ครั้งต่อหนึ่งตัวอักษร)

> [!IMPORTANT]
> 🏆 **ผลลัพธ์จากการถอดรหัส (Decoded Secret Message):**
> ตัวอักษรที่แฮกเกอร์ทิ้งไว้เมื่อนำมาเรียงกันจะได้ข้อความดังนี้:  
> **`NEXUS_CART_WAS_TO_EASY_YOUR_SYSTEM_WAS_ALREADY_FALING_APART_BEFORE_YOU_EVEN_REALIZED_IT_WAS_MEGOEMON`**

*(หมายเหตุ: ข้อมูลทั้งหมดของ Hackathon #1 จะถูกนำเสนอในรูปแบบ Dashboard)*

## 📊 Hackathon #2: Environmental Data Science

**โจทย์:** การใช้ Data Science เพื่อวิเคราะห์ข้อมูลดิบจากเซ็นเซอร์ตรวจวัดกลิ่นและสภาพแวดล้อม โดยเป้าหมายหลักคือการค้นหาค่าที่ผิดปกติ (Anomalies) จากข้อมูลจริง เพื่อช่วยระบุช่วงเวลาหรือจุดที่น่าสงสัยและจัดทำรายงานสรุปข้อมูล

### 🔬 วิธีการวิเคราะห์ในสคริปต์ (`t.py`)
โปรแกรมการทำงานบนภาษา Python (`t.py`) มีการวิเคราะห์ข้อมูลตามลำดับดังนี้:
1. 📥 **อ่านข้อมูล (Read Data)**: อ่านข้อมูลดิบจากไฟล์ Excel ชื่อ `hack.xlsx`
2. 🧹 **ทำความสะอาดข้อมูล (Data Cleaning)**:
   - ลบแถวที่ค่าในคอลัมน์ **Temperature** (อุณหภูมิ) หรือ **Relative Humidity** (ความชื้นสัมพัทธ์) หายไป (Null / NaN)
   - ตัดแถวที่เป็นศูนย์ทั้งหมดออกจากการวิเคราะห์
3. 📈 **ระบุค่าผิดปกติด้วยวิธี IQR (Anomaly Detection)**:
   - ใช้วิธี **Interquartile Range (IQR)** ในการคำนวณหาขอบเขตของข้อมูลที่เหมาะสม (ปกติ) สำหรับค่าอุณหภูมิและความชื้น
   - ทำการตรวจสอบแถวข้อมูล หากมีค่าสูงหรือต่ำกว่าขอบเขตที่คำนวณได้ จะทำการแปะป้ายระบุว่าเป็น **ค่าผิดปกติ (Anomaly)**
4. 📝 **สรุปและส่งออกผลรายงาน (Report Generation)**:
   - สรุปสถิติพื้นฐาน เช่น จำนวนข้อมูลทั้งหมด, จำนวนค่าที่ผิดปกติที่ตรวจเจอ
   - บันทึกผลลัพธ์ทั้งหมดลงในไฟล์รายงาน (`report.csv`)

### 📝 สรุปความสำคัญในการส่งผลงาน (Executive Summary)
> **"โครงงานนี้ใช้หลักการ Data Science วิเคราะห์ข้อมูลจากเซ็นเซอร์ตรวจวัดกลิ่นและสภาพแวดล้อม โดยนำข้อมูลมาทำความสะอาด จากนั้นใช้ IQR ตรวจหาค่าผิดปกติของอุณหภูมิและความชื้น เพื่อช่วยระบุช่วงเวลาหรือจุดที่น่าสงสัย และสรุปผลออกมาเป็นรายงานเพื่อนำไปใช้ต่อได้"**
